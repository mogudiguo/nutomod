========================================
  NutonMod 模板 - 中文路径问题解决方案
========================================

问题原因:
---------
Windows 用户名包含中文字符（真夜中），导致 Gradle Worker Daemon 在反编译时
无法正确处理包含中文的路径，出现编码错误和 IO 异常。

解决方案 3 - 移动项目到无中文路径:
----------------------------------

步骤 1: 运行移动脚本
---------------------
双击运行当前目录下的：move-project.bat

这会将项目复制到 D:\nutonmod-template-1.21

步骤 2: 打开新项目
---------------------
在新位置 D:\nutonmod-template-1.21 中打开项目

步骤 3: 使用开发助手
---------------------
在新位置双击运行：dev-helper.bat

或者手动执行命令:
.\gradlew build              # 构建项目
.\gradlew runClient          # 运行客户端
.\gradlew runServer          # 运行服务器

注意事项:
---------
1. 原项目文件会保留在桌面
2. 建议只在新位置进行开发
3. Gradle 缓存会存储在 D:/gradle-cache
4. 所有编译和运行操作都在无中文路径下进行

技术配置:
---------
已在 gradle.properties 中配置:
- JVM 编码参数：UTF-8
- Gradle 用户目录：D:/gradle-cache
- 最大堆内存：4GB
- 元空间大小：2GB

如果仍有问题:
-------------
1. 确保目标路径不存在中文文件夹名
2. 可以尝试直接运行：.\gradlew build --no-daemon
3. 或者使用 IDEA/VSCode 的内置终端执行命令
